Sobre elementos de listas

Listas são uma das coisas mais importantes no HTML. Elas aparecem o tempo todo em páginas web.

Conhecendo as listas

Lista não ordenada

Usamos a lista não ordenada quando a ordem dos itens não é importante.

  • Arroz
  • Feijão
  • Macarrão
  • Café
  • Banana

Lista ordenada

Usamos a lista ordenada quando a ordem dos itens é importante.

  1. Comprar ingredientes
  2. Misturar os ingredientes
  3. Colocar no forno
  4. Comer

Lista de descrição (dl)

Esse tipo de lista serve para representarmos termos e suas respectivas descrições.

HTML
É a linguagem de marcação utilizada para estruturar páginas web.
CSS
É a linguagem de estilo utilizada para estilizar páginas web.
JavaScript
É a linguagem utilizada para adicionar comportamentos a páginas web.
